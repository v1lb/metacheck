# MetaCheck 2.1 — Cyber Grid / Neon Intelligence

## Архитектура

- `domain/analysis`: проверяемые по JVM правила выявления ИИ-маркеров в метаданных. **Не оценивает достоверность изображения по пикселям.**
- `domain/analytics`: статистика из сохранённых отчётов, реальные 7-дневные интервалы.
- `domain/export/HistoryCsv`: CSV с BOM, RFC4180-кавычками и нейтрализацией формул табличных процессоров.
- `data/parser`, `data/clean`, `data/export`: разбор, очистка и экспорт файлов.
- `data/history`: зашифрованные отчёты в приватной папке. Изображения не хранятся в истории.
- `data/settings`: пользовательские параметры, API-ключ в Android Keystore.
- `data/billing`: реальный Google Play Billing одноразового продукта `pro_lifetime`.
- `ui/MainScreen`: выбор файла, камера, буфер, onboarding, история и статистика.
- `ui/ResultView`: безопасное превью (до 1024px), оценка метаданных, вкладки, экспорт и EXIF.
- `ui/CyberDesign`: общий дизайн Compose Canvas/Brush/Material 3 (без WebView, JS и CSS).
- `ui/SettingsScreen`, `ui/ProUi`: настройки, приватность и реальная покупка/лицензия.

## Достоверность и безопасность

- Нет AI confidence %, поскольку алгоритм анализирует метаданные, а не пиксели.
- Нет "покупки" или выдачи платного статуса без Google Play Billing либо валидного подписанного лицензионного ключа.
- Для Play необходимо создать одноразовый INAPP товар `pro_lifetime` и распространять приложение по корректному Play-каналу. Debug APK не гарантирует доступность платежей.
- `LicenseKey.PUBLIC_KEY_BASE64` должен содержать публичный ключ владельца проекта; пока он пуст, ручные лицензионные ключи не работают.
- Enterprise/Stripe/ЮKassa/криптоплатежи намеренно не представлены как работающие: без серверного биллинга, верификации платежей и условий распространения приложения это было бы небезопасно.
- Сетевой API направляет только JSON, при явном согласии пользователя. Сохраняйте ключи вне git.
- Свечение и сетка рисуются Canvas; прозрачные карточки симулируют стекло, но настоящее размытие подложки не включено для производительности и поддержки Android 8+.
