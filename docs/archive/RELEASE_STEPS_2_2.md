# Как обновить MetaCheck через Termux

1. Скачайте ZIP в папку Download на телефоне.
2. Используйте команды из ответа ChatGPT. Они заменят исходники, не удаляя `.git`.
3. Не загружайте токен GitHub или файлы `keystore.properties` в коммиты.
4. Дождитесь зелёной проверки **Actions → CI** для **нового коммита**.
5. Скачайте **MetaCheck-debug-apk**, распакуйте ZIP и установите `app-debug.apk`.
6. Проверьте на телефоне: белые заголовки/числа, просмотр метаданных, поиск «ISO» и «GPS», категории, экспорт CSV, JSON/PDF в Pro, сохранённую историю и удаление метаданных.

Debug APK предназначен для испытаний. Для Google Play нужен отдельный подписанный release AAB и проверка биллинга.
