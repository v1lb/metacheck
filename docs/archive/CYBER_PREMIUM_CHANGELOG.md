# MetaCheck — Cyber Premium UI

- Фиксированная тёмная палитра Cyber Premium вместо динамической системной темы.
- Обновлены информационные карточки: тонкая рамка, компактные разделители, улучшенная иерархия значений.
- Добавлена сводка результата анализа с явным предупреждением об ограничениях анализа метаданных.
- Сокращены названия вкладок и улучшены цвета навигации.
- Исправлена конфигурация GitHub Actions: `setup-android` устанавливает `platform-tools` вместо недоступного пакета `tools`.
- Логика анализа, экспорта, очистки, API и история не изменены.
