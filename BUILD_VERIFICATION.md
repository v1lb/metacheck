# Техническая проверка Cyber Premium 2.1

## Проверено непосредственно

- ZIP архив распаковывается без ошибок, все исходные файлы включены.
- Скомпилированы изолированно с `kotlinc` чистые Kotlin-модули `domain/analytics/HistoryInsights.kt`, `domain/export/HistoryCsv.kt` и модели домена.
- Запущена локальная Kotlin-проверка: расчёт временных интервалов и безопасная сериализация CSV с формульными строками.
- Конфигурация `.github/workflows/ci.yml` проверена на корректную структуру YAML.
- Для Compose UI тесты `ResultViewTest.kt` актуализированы под новый интерфейс, но НЕ запускались.

## Не подтверждено

- Полная сборка APK, `lintDebug`, автоматические JVM/инструментальные тесты Android.
- Работа on-device на различных Android 8–16.
- Оплата в Google Play, т.к. продукт Play Console и учётные данные не предоставлены.
- Серверные платежи (Stripe/ЮKassa/Crypto/Enterprise) не реализованы; декоративной симуляции платежей нет.
- Претензия на production-ready и оценка 10/10 не подтверждена без CI и испытаний.

## CI

1. Распаковать архив и загрузить файлы в корень git-репозитория.
2. `git add . && git commit -m "Cyber Grid Neon Intelligence 2.1" && git push origin main`
3. В GitHub Actions открыть `CI` и дождаться зелёной галочки.
4. Скачать `MetaCheck-debug-apk` → `app-debug.apk`.
5. При красном крестике раскрыть `Run unit tests, lint and build APK` и проверить ошибку; не устанавливать APK от неуспешной сборки.

Для стабильного релиза нужен подписанный APK/AAB и ручная проверка критических сценариев на Android.
